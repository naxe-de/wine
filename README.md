# Wine

Is it a good moment to open a bottle? A dial that follows Maria Thun's biodynamic wine calendar.

Open `index.html`. One file, no dependencies, nothing stored.

Drag the bottle around the day. Red is yes, grey is no.

The Moon's position among the constellations is computed in the browser and mapped to Thun's fruit, flower, leaf and root days. Checked against the JPL ephemeris for all of 2026.

School project.
